# rate-my-bites-game
A standalone prototype for the Rate My Bites group dining game, featuring cinematic stories, people-centered clues, restaurant and order predictions, scoring, and local episode progress.

Release `v0.4.6.0` adds the reusable Multi-Episode Foundation. Episode content and the centralized catalog live in `episodes.js`; progress is local-only and versioned in `episodeProgress.js`.
